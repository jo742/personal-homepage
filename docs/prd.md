# 需求文档

## 1. 应用概述

### 1.1 应用名称
江宇梦的个人主页

### 1.2 应用描述
一个简约清新的个人主页网站,用于展示江宇梦的个人信息、兴趣爱好和近期动态,并提供数字分身聊天功能,方便访客了解和互动。

## 2. 用户与使用场景

### 2.1 目标用户
- 朋友:了解江宇梦的近况和兴趣
- 潜在合作伙伴:评估合作可能性
- 面试官:了解候选人背景和特点

### 2.2 核心使用场景
- 访客通过链接访问主页,快速了解江宇梦的基本信息
- 访客通过数字分身聊天区提问,获取更多信息
- 访客在移动端浏览主页

## 3. 页面结构与功能说明

### 3.1 页面结构
```
个人主页
├── 头部区域
│   ├── 头像
│   ├── 名字
│   └── 一句话介绍
├── 个人信息展示区
│   ├── 我现在主要在做
│   ├── 我的兴趣
│   └── 我的特点
└── 数字分身聊天区
    ├── 聊天对话框
    ├── 输入框
    └── 发送按钮
```

### 3.2 功能说明

#### 3.2.1 头部区域
- 展示头像
- 展示名字「江宇梦」
- 展示一句话介绍「一个正在学习用 AI 做产品的研二学生」

#### 3.2.2 个人信息展示区
- 展示「我现在主要在做」:学习AI产品经理的相关技能为明年毕业就业做准备
- 展示「我的兴趣」:AI应用、爬山、旅行
- 展示「我的特点」:梗王:不经意间说出一个梗

#### 3.2.3 数字分身聊天区
- 访客在输入框输入问题
- 点击发送按钮提交问题
- 聊天对话框展示访客问题和数字分身回复
- 数字分身基于以下信息回答问题:
  - 职业或身份:学生
  - 最近在做的事:搭自己的个人主页,用ai做作品
  - 擅长或关心的方向:内容表达、AI 应用、知识整理
  - 常见问题:
    - 你现在在做什么?
    - 你的兴趣是什么?
    - 你关心的方向是什么?

## 4. 业务规则与逻辑

### 4.1 数字分身回复规则
- 数字分身根据预设信息生成回复
- 回复内容需符合江宇梦的身份和特点
- 对于预设常见问题,优先使用预设答案
- 对于其他问题,基于预设信息进行合理推断回答

### 4.2 移动端适配规则
- 页面布局在移动端自动调整为单列布局
- 文字大小和间距适配移动端屏幕
- 聊天区输入框和按钮适配移动端操作

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 访客输入空白问题 | 提示「请输入问题」 |
| 数字分身无法回答的问题 | 回复「抱歉,我暂时无法回答这个问题,你可以尝试问我其他问题」 |
| 头像加载失败 | 显示默认占位图 |
| 网络异常导致聊天失败 | 提示「网络异常,请稍后重试」 |

## 6. 验收标准

1. 访客打开主页,看到头像、名字「江宇梦」和一句话介绍「一个正在学习用 AI 做产品的研二学生」
2. 访客在个人信息展示区看到「我现在主要在做」「我的兴趣」「我的特点」三项信息
3. 访客在数字分身聊天区输入问题「你现在在做什么?」并点击发送
4. 聊天对话框展示访客问题和数字分身回复「我现在主要在搭自己的个人主页,用ai做作品」
5. 访客在移动端打开主页,页面布局自动适配移动端屏幕
